# 陽光留下的藍色影像｜藍曬圖實驗室

給國小中、高年級使用的科學 × 藝術互動教材。課程包含藍曬科學原理、透光預測、公平測試、線上概念模擬、教師指導下的真實實作、構圖任務與形成性評量。

## 公開網站

https://prayer168.github.io/cyanotype-lab/

## 本機執行

```powershell
npm.cmd install
npm.cmd run dev
```

正式建置：

```powershell
npm.cmd run check
npm.cmd run build
```

## 教學安全

- 中高年級學生預設使用預塗藍曬紙。
- 感光液的配製、塗布、保存與廢棄物處理由教師依供應商 SDS、學校規定及所在地規範執行。
- 不將感光材料與酸、漂白水或其他未經產品指示的化學品混合。
- 戶外曝光需同時執行兒童防曬與護眼措施，不直視太陽或人工 UV 光源。
- 線上模擬只呈現相對關係，不預測實際曝光分鐘數。
